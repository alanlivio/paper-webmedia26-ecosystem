# paper-webmedia26-ecosystem

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Repository for the academic paper **New Ginga Developer Ecosystem with ginga.org.br, ginga-playground and ginga-code**.

- `paper/` — LaTeX source
- `website/` — static webpage using Zensical

At `website`, do `make help` to see all available commands. The deployment to GitHub Pages is handled by [deploy.yml](.github/workflows/deploy.yml).
